# Security Policy

## Showcase Repository Notice
This repository is primarily an **engineering showcase and portfolio demonstration project**, designed to document microcontroller signal generation concepts and hardware validation results. It is not intended as production-grade enterprise software.

## Supported Scope
| Version / Branch | Supported | Notes |
|:---|:---:|:---|
| Main Showcase Branch | Yes | Active portfolio documentation |

## Reporting Vulnerabilities
If you discover a potential security vulnerability or sensitive information exposure in this documentation showcase, please report it responsibly:

1. **Contact Method:** Please submit a private security report through GitHub's private vulnerability reporting feature or contact the repository maintainers directly.
2. **Details to Include:** Describe the nature of the vulnerability or data issue, affected files, and steps to reproduce.
3. **Response Timeline:** Maintainers will acknowledge receipt of reports within **48 hours** and provide periodic updates regarding resolution.

Please do not disclose security vulnerabilities publicly in open issues until the issue has been addressed by maintainers.
