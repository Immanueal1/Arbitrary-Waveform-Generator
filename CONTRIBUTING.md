# Contributing Guidelines

Thank you for your interest in the **Raspberry Pi Pico Arbitrary Waveform Generator** showcase project.

## Repository Purpose
This repository is primarily an **engineering portfolio showcase** designed to document hardware architecture, signal generation design patterns, and hardware validation results.

Because this is a showcase repository:
* **Significant Architectural Changes:** Please open an issue to discuss major proposed architectural or documentation changes before implementing them.
* **Bug Fixes & Improvements:** Bug reports, documentation clarifications, and typo fixes are welcome via Issues and Pull Requests.

## How to Contribute

### 1. Reporting Issues
* Search existing issues to ensure your topic has not already been reported.
* Use clear, descriptive titles and include steps to reproduce any documentation or technical formatting errors.

### 2. Submitting Pull Requests (PRs)
* Keep pull requests focused on a single change or fix.
* Maintain clean formatting, concise commit messages, and adherence to existing Markdown formatting standards.
* Ensure all links and image references build correctly before submitting.

### 3. Standards & Communication
* **Documentation Quality:** Maintain professional engineering language, accurate technical descriptions, and clear figure captions.
* **Respectful Communication:** All interactions in issues and PRs must adhere to our [Code of Conduct](CODE_OF_CONDUCT.md).
